✨ WHAT CHIP SLICER DOES
The built-in Power BI list slicer is functional but takes up a lot of space and
hides the context of what's selected. Chip Slicer renders each category value as
a clickable chip — you can see every option and every selection at a glance,
without scrolling or expanding a dropdown.

🔑 KEY FEATURES
→ Single-select and multi-select modes
→ Horizontal (wrapping) and vertical (stacked) layout
→ Full color control: background, border, and text for active + inactive states
→ Configurable chip height, border radius, font size, padding, and gap
→ Optional "Select All" button with customizable label
→ Slicer sync across report pages
→ High contrast mode support
→ Full keyboard accessibility (Tab, Enter, Space)
→ Landing page when no field is assigned
→ Up to 1,000 values per slicer
→ Zero external dependencies — no network calls, no telemetry
→ Microsoft certified

💸 PRICING
