Chip Slicer for Power BI 1.5 — free button slicer with default selection, clear button and counts on chips

The native slicer opens with nothing selected and makes the reader open a list. Chip Slicer turns a field into
buttons that filter the page with one click — and it is free for everyone, with every feature.

In this video:
• Drop a field into Category: one chip per value
• Default selection: the report opens on this year (or the values you choose)
• Clear button and "All" chip
• A measure in Value: counts or totals on each chip, sorted by value
• Horizontal, vertical or grid layout
• Six style templates: Classic, Outline, Soft, Square, Segmented, Dark
• On-object formatting, keyboard and 12 languages
