How it works
1
Add the Visual
Import from AppSource or .pbiviz file. Appears in your Visualizations panel.
2
Drop a Field
Drag any categorical column into the Category well. Chips render instantly.
3
Click to Filter
Click any chip to apply a filter to all visuals on the page.
4
Combine Values
Enable Multi-select in Format Pane to filter by multiple values at once.
5
Style It
Open the Format Pane to match your report's theme and branding.
6
Sync Pages
Use Power BI's Sync Slicers panel to keep filters consistent across pages.

Key Benefits
  • Compact layout — fits more filters in the same space as a single dropdown
  • Instant visual feedback — active state is always clear at a glance
  • No learning curve — users already know how to click chips
  • Accessible — keyboard and screen reader friendly out of the box
  • Zero performance overhead — no external libraries or network calls
Tips & Best Practices
  • Use horizontal layout in report headers for a navigation-bar feel
  • Keep labels short — chips are designed for concise category names
  • Match Active Background to your report's accent color for brand consistency
  • Enable Multi-select for exploratory dashboards, disable it for guided analysis
  • Use the Sync Slicers panel to share state across all report pages
  • Increase Border Radius to 50% for the classic pill/lozenge look
