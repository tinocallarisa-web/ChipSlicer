How it works
1
Add the Visual
Get it from AppSource: Visualizations pane → Get more visuals.
2
Drop a Field
Drag a column into Category: one chip per value, up to 1,000.
3
Add a Measure
Optional: a measure in Value shows a count or total on each chip.
4
Click to Filter
Click a chip to filter the page. Click it again, ✕ or All to clear.
5
Pick a Template
Format pane → Style template changes the whole look in one click.
6
Set a Default
Default selection opens the report on the values you choose.

Tips & Best Practices
  • Year in Category + Default selection opens on the current year
  • A count measure in Value + Sort by value shows sizes first
  • COALESCE([Measure], 0) keeps items with no value visible
  • Grid with 0 columns fits long lists in a small tile
  • Segmented template + Multi-select reads like a switch
  • Several levels? Use Chip Slicer Hierarchy
