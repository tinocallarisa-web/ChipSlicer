CHIP SLICER — TIPS & HINTS
Version 1.5.0.0 · Free for everyone · tcviz.com
________________________________________

GETTING STARTED
---------------
1. Install — Add Chip Slicer from AppSource (Visualizations pane > Get more visuals).
2. Drop a field — Drag a column into the Category field well. One chip per value.
3. Optional: add a measure — Drag a measure into Value to show a count or total on each chip.
4. Filter — Click a chip to filter the page. Click it again, the ✕ button or "All" to clear.
5. Pick a look — Format pane > Style template changes the whole look in one click.

While you edit, a tips bar at the bottom of the visual offers the templates. Hide it with ✕
(it comes back from Format > Style template > Show setup tips). It never shows in reading view.

Overview video: https://www.youtube.com/watch?v=uArWJsB_n7w

FIELD WELLS
-----------
· Category ......... 1 column (text, number, date, true/false) or a hierarchy level
· Limit ............ Up to 1,000 values
· Value ............ Optional. 1 measure, shown on each chip with the model's format
· Note ............. With a measure in Value, items for which the measure is blank are not shown.
                     Remove the field from Category to see the start screen.

________________________________________

FORMAT PANE
-----------

STYLE TEMPLATE
· Template .................. Default: Classic. Classic, Outline, Soft, Square, Segmented or Dark.
· Show setup tips ........... Default: On. Tips bar while editing (never in reading view).

TEMPLATES
· Classic ................... Grey pills, blue when selected. The look of earlier versions.
· Outline ................... White pills with a blue outline and a check mark when selected.
· Soft ...................... Pale blue pills, solid blue when selected.
· Square .................... Small corners, black when selected.
· Segmented ................. Joined square buttons, like a segmented control.
· Dark ...................... For dark report backgrounds.
A template fills in what you have not changed yourself. When you pick a template, the colours
and shapes it defines replace yours; anything else you changed stays.

CHIP STYLE — SELECTION
· Multi-select .............. Default: Off. On = every click toggles a chip.
· Show "All" button ......... Default: On. Adds a chip that clears the filter.
· "All" button text ......... Default: "All". Change to any label you like.
· Show clear button ......... Default: On. ✕ that clears the selection; only shows when something is selected.
· Default selection ......... Default: empty. Values separated by commas, selected when the report
                              opens with nothing selected in this slicer.
· Sort ...................... Default: Data order. Data order, A to Z, Z to A, or Value, largest first.

CHIP STYLE — LAYOUT
· Layout .................... Default: Horizontal. Horizontal, Vertical or Grid.
· Columns ................... Default: 0. Grid columns; 0 = automatic.
· Wrap to next line ......... Default: On. Off = a single row with horizontal scrolling.
· Stretch chips to fill ..... Default: Off. Chips share the available width.
· Alignment ................. Default: Left. Left, Center or Right.
· Gap (px) .................. Default: 8

CHIP STYLE — CHIPS
· Chip height (px) .......... Default: 34
· Border radius (px) ........ Default: 17 (= half height for a full pill shape)
· Horizontal padding (px) ... Default: 16
· Font ...................... Default: Segoe UI
· Font size ................. Default: 12
· Check mark on selected .... Default: Off
· Shadow .................... Default: On

CHIP STYLE — COLORS (Classic defaults)
· Inactive background ....... #F3F4F6
· Inactive border ........... #E5E7EB
· Inactive text ............. #374151
· Active background ......... #378ADD
· Active border ............. #378ADD
· Active text ............... #FFFFFF

HEADER
· Show header ............... Default: Off. Title above the chips.
· Text ...................... Empty = the field name.
· Font, Font size, Bold, Color  Defaults: Segoe UI Semibold, 12, Off, #252423

VALUES (appears only when there is a measure in Value)
· Show value on chips ....... Default: On
· Color ..................... Default: automatic

ON-OBJECT FORMATTING
With Format on, click a chip, the header or a chip value to see its options next to it.
In format mode a click chooses what to format and does not filter.

TIPS & BEST PRACTICES
---------------------
· Start from a template — Pick the closest template, then change only what you need.
  Use Reset to default on a colour to let the template decide it.
· Open on the current period — Put Year in Category and type it in Default selection;
  the ✕ goes back to all years.
· Show sizes before clicking — Put a count measure in Value and Sort by value.
· Show items with no value — Wrap the measure as COALESCE([Measure], 0) so blank items still appear.
· Long lists in small tiles — Grid with Columns = 0 and a smaller chip height.
· One row with scrolling — Horizontal layout with Wrap to next line off.
· Status toggles — Segmented template with Multi-select on reads like a switch.
· Header slicers — Horizontal layout in a report header gives a navigation-bar look.
· Sidebar slicers — Vertical layout in a narrow side panel.
· Full pill look — Border radius = half of Chip height (e.g. height 34 = radius 17).
· Ctrl+click — Adds chips to the selection even when Multi-select is off.
· Slicer sync — View > Sync slicers keeps the selection across report pages. Bookmarks save it too.
· Several levels — Chip Slicer uses one level. For country > city with expand and collapse,
  use Chip Slicer Hierarchy: https://tcviz.com/product/chip-slicer-hierarchy/

________________________________________

KEYBOARD
--------
One Tab stop for the whole slicer. Arrow keys, Home and End move between chips;
Enter or Space select (Ctrl adds); Escape clears; Shift+F10 opens the context menu.

TROUBLESHOOTING
---------------
· Chips don't appear
  > Add a field to the Category well.

· Clicking a chip does not filter other visuals
  > Check Format > Edit interactions, and that the field is related to their tables in the model.

· Some values are missing
  > With a measure in Value, blank items are hidden. Other page filters also reduce values.
    Beyond 1,000 values the rest are not loaded.

· Default selection does not apply
  > It only applies when the report opens with nothing selected in this slicer (a bookmark or
    saved selection wins). The text must match the chip text. Separate values with commas.

· A template did not change some colours
  > A template changes only what it defines. Use Reset to default on a colour.

· The tips bar covers the chips
  > It only shows while editing. Close it with ✕ or turn off Show setup tips.

· Dates look different from my table
  > Chips use the column's format in the model (Column tools > Format).

· A hierarchy filters only the first level
  > Expected: Chip Slicer is one level. Use Chip Slicer Hierarchy for several levels.
