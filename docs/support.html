Chip Slicer turns a field into a row of buttons — chips — that filter the page with one click. It is free for everyone: there is no Pro tier, no licence and no watermark. The selection is a standard Power BI filter (sync slicers, bookmarks, edit interactions). It opens on the values you choose, even after the reader cleared them last time, can keep one value always selected, shows the value of a measure on each chip, groups the chips that do not fit into “+N” and changes its whole look in one click, following the report theme by default.

Quick start

  1. Add Chip Slicer from AppSource (Visualizations pane → Get more visuals).
  2. Drag a column into Category: one chip per value.
  3. Optional: drag a measure into Value to show a count or total on each chip.
  4. Click a chip to filter the page. Click it again, the ✕ button or All to clear.
  5. The chips take the colours of the report theme (Report theme template). In the Format pane, Style template changes the whole look in one click.

While you edit, a tips bar at the bottom of the visual offers Report theme, Classic and the six collection styles; hide it with ✕ (it comes back from Format → Style template → Setup guide). It never shows in reading view.

Selecting and clearing

  • Single select (default): a click selects one chip; clicking it again clears it. Ctrl+click adds chips even in single-select mode.
  • Multi-select (Format → Chip Style → Selection): every click toggles a chip.
  • All chip: clears the filter. Its text can be changed.
  • Clear button ✕: in the header when it is on; otherwise in the top-right corner. It only shows when something is selected.
  • Default selection: type values separated by commas, e.g. Spain, France. When the report opens with nothing selected in this slicer, those values are selected. If the user clears them, the slicer stays clear until the page is opened again. Values match the chip text, without case or accents. In single-select mode the first match is used.
  • Force selection (Format → Chip Style → Selection, off by default): the slicer always keeps a value selected. When nothing valid is selected it applies the Default selection if you set one, otherwise the first non-blank value in the order shown. This also happens when a bookmark without a filter is applied, or when the selected value disappears because another slicer filtered this one. The All chip, its text setting and the clear button are hidden (in the visual and in the Format pane); clicking the selected chip or pressing Escape does not clear it, and with Multi-select the last selected value cannot be removed. It does not act in format mode or where Power BI disallows interactions.

The selection is a standard Power BI filter: it follows sync slicers, is saved in bookmarks, respects edit interactions and filters the other visuals of the page.

  • Highlighting: when another visual on the page highlights part of the data, the chips without data in that highlight are dimmed.
  • Context menu: right-click a chip (or Shift+F10) for the Power BI context menu.

Chips that do not fit: “+N”

In a Horizontal layout with Wrap to next line on, when the chips need more rows than the box has, the last ones are grouped into a “+N” chip with a dashed border, N being how many are hidden. Click it, or press Enter or Space on it: all the chips are shown with a vertical scroll and a “Show less” chip at the start. “Show less” or Escape closes the list again.

  • Selected chips are never hidden behind “+N”. If even the selected chips do not fit, the slicer scrolls as before.
  • With the keyboard, opening moves the focus to the first chip revealed, and closing returns it to “+N”.
  • Opening and closing is only the reader's view: nothing is saved in the report.
  • Vertical and Grid layouts, or Wrap to next line off, scroll as before.
  • Setting: Format → Chip Style → Layout → Group chips that don't fit (+N), on by default.

On-object formatting

With Format on, click a chip, the header or a chip value to see its options next to it: font, size and colours, quick toggles (multi-select, All button, check mark, show header…) and a link to its card in the Format pane. In format mode a click chooses what to format and does not filter. As with native visuals, the first click selects the visual and the second the part.

Languages, number formats and accessibility

  • Format pane and texts in English, Spanish, Portuguese (Brazil and Portugal), French, German, Italian, Dutch, Polish, Japanese, Chinese (Simplified) and Korean, following the language of Power BI.
  • Dates and numbers in the chips, and the values from the Value well, use the format of the model and the report locale. Dynamic format strings of the measure are respected.
  • Keyboard: one Tab stop for the whole slicer; arrow keys, Home and End move between chips; Enter or Space select (Ctrl adds); Escape clears (unless Force selection is on; with "+N" open, Escape first closes it); Shift+F10 opens the context menu.
  • Screen readers: announced as a list, with each chip's state (selected or not) and its value.
  • High contrast: the chips take the colours of the Windows high-contrast theme.
  • Themes: with the Report theme template (the default) the chips, header and clear button take the colours of the report theme, light or dark, and the header colour follows the theme where you leave it unset. Fonts do not change with the theme.
  • “+N”: reachable with the keyboard like any chip; Enter or Space opens it and Escape closes.

Use cases

1. Year or quarter buttons on a dashboard

Put Year in Category, layout Horizontal, Default selection 2026. The page opens on the current year and the reader switches with one click; the ✕ goes back to all years.

2. Region filter with counts

Region in Category, Customers = DISTINCTCOUNT(Sales[CustomerID]) in Value, Sort by value. The reader sees how big each region is before clicking, and regions without customers disappear.

3. A long list in a small space

Product in Category, Grid with automatic columns and a smaller chip height: dozens of products fit in a tile and scroll inside it.

4. Status toggles

Status (Open, In progress, Closed) with the Segmented template and Multi-select on: it reads like a switch.

5. Always one period selected

Month or Year in Category with Force selection on: the page never shows all periods mixed. Set a Default selection for the period it should open on; otherwise the first value is used.

6. Many values in a narrow strip

A one- or two-row strip at the top of the page, layout Horizontal with wrapping: the values that do not fit go into “+N”, and the reader opens it when needed.

Troubleshooting

Clicking a chip does not filter the other visuals

Check Format → Edit interactions: the other visuals must be set to filter from Chip Slicer. Check also that the field in Category is related to the tables of the other visuals in the model.

Some values are missing
  • With a measure in Value, values for which the measure is blank are not shown. Remove the measure, or wrap it as COALESCE([Measure], 0) to show them with 0.
  • Other filters on the page or report reduce the values, as with any slicer.
  • Beyond 1,000 distinct values the rest are not loaded. Split the list with another slicer or use Chip Slicer Hierarchy.
The default selection does not apply
  • It only applies when the report opens with nothing selected in this slicer. A bookmark or a saved selection wins.
  • The text must match the chip text, e.g. a date as it appears on the chip. Separate values with commas.
  • If the value is filtered out by another filter, there is nothing to select.
After updating, my slicer looks different

Since 1.6 the default template is Report theme. Reports that never chose a template take it after the update. Choose Classic in Format → Style template to get the earlier look back. Colours you had set by hand are kept.

A “+N” chip appeared instead of the scroll bar

Since 1.6, in a horizontal layout with wrapping, the chips that do not fit are grouped into “+N”. To scroll as before, turn off Format → Chip Style → Layout → Group chips that don't fit (+N).

The All chip or the clear button ✕ disappeared, and I cannot clear the selection

Force selection is on (Format → Chip Style → Selection). It keeps one value always selected, so it hides the ways to clear. Turn it off to clear the slicer again.

I chose a template and some colours did not change

A template changes only what it defines; the others keep your settings. Use Reset to default on a colour to let the template decide it.

“+N” does not open

“+N” cannot be opened where the report does not allow interactions (for example a dashboard tile); the grouped chips stay hidden there.

The Setup guide bar does not appear

The Setup guide bar only appears while editing and when the visual is at least 300 × 150 px. Check also Format → Style template → Setup guide.

The tips bar covers my chips

It only appears while you edit. Close it with ✕ or turn off Format → Style template → Setup guide.

Dates appear in a different format than in my table

Chips use the format of the column in the model. Set the column's format in Power BI (Column tools → Format).

Frequently asked questions

Is Chip Slicer really free? Are there hidden limits?

Yes, free for everyone, with every feature. There is no Pro tier and no licence. The only limits are technical and the same for everyone: one field in Category, one measure in Value, and up to 1,000 distinct values.

How do I select several chips?

Turn on Format → Chip Style → Selection → Multi-select, or hold Ctrl while clicking.

How do I clear the selection?

Click ✕, the All chip, the selected chip again (single select), or press Escape with the keyboard. With Force selection on, the selection cannot be cleared.

Can the slicer always keep one value selected?

Yes: Format → Chip Style → Selection → Force selection. It applies the Default selection, or else the first value, whenever nothing is selected.

What is the “+N” chip?

The chips that do not fit in the box, grouped. Click it to see them all and “Show less” to close. See Chips that do not fit.

Can it use the colours of my report theme?

Yes. The Report theme template, the default since 1.6, takes them from the theme, light or dark.

Can it match my other TCViz visuals?

Yes. Pick Boardroom, Ledger, Editorial, Signal, Aurora or Terrace: the same styles as KPI Card, Histogram and the rest of the collection. They are free in Chip Slicer.

Can the report open with a value already selected?

Yes: Format → Chip Style → Selection → Default selection. See Selecting and clearing.

How do I keep the filter when I change page?

Use View → Sync slicers and add Chip Slicer to the pages you want.

Do bookmarks remember the selection?

Yes. The selection is a Power BI filter, saved and restored by bookmarks like any slicer.

Can I show counts on the chips?

Yes: put a measure in Value (a count, a total, a percentage). It uses the measure's format.

Can I sort the chips?

Format → Chip Style → Selection → Sort: data order (the model's sort, including Sort by column), A to Z, Z to A, or by value when there is a measure.

Can I put the chips in columns?

Yes: Layout → Grid, and choose the number of columns or 0 to fit as many as the width allows.

Can I put the chips in one row with scrolling?

Layout Horizontal and turn off Wrap to next line.

Does it work with dates, numbers and codes such as 08001?

Yes. The filter uses the original value and type, so a text code keeps its leading zeros and dates filter correctly.

Can I filter by several levels, such as country → city?

Chip Slicer uses one level: if you drop a hierarchy into Category it filters by its first level. For several levels with expand and collapse, use Chip Slicer Hierarchy, our slicer built for that.

Does it work with tables with a dot in the name?

Yes, since 1.4.1.

Does it work in the Power BI service, apps and mobile?

It works wherever custom visuals from AppSource work. Where Power BI disallows interactions (some exports and embedded views), the chips are shown but do not change the filter.

Does it support high contrast and keyboard?

Yes. See Languages, number formats and accessibility.

Why is it called “Chip Slicer Pro” in some places?

That was the name of an earlier paid version. Since 1.4 it is free and every feature is included.

Does the visual send my data anywhere?

No. It makes no network calls, has no telemetry, sets no cookies and stores nothing outside the report. The links on the start screen open only when you click them, through Power BI. See the privacy policy.
