Quick Start

  1. Get the visual. Install Chip Slicer from Microsoft AppSource, or import the .pbiviz file via the Visualizations panel (⋯ → Import a visual from a file).
  2. Add it to the canvas. Click the Chip Slicer icon in the Visualizations panel. A blank visual appears.
  3. Drop a field. Drag any categorical column (text, date, number) from your data model into the Category field well. Chips render instantly.
  4. Click a chip to filter. All other visuals on the page respond to the selection.
  5. Click it again (or click "All") to clear the filter.

Frequently Asked Questions

Is Chip Slicer really free? Are there any hidden limits?

Yes, completely free. There are no tiers, no paywalls, and no license required. All features — including multi-select, full color customization, and the "All" button — are available to every user. The only limit is 1,000 values per field well, which is a Power BI platform cap applied to all custom visuals.

How do I select multiple chips at once?

Open the Format Pane → Chip Style → turn on Multi-select. Once enabled, each chip click toggles independently. Click "All" (or the custom label) to clear all selections at once.

How do I keep the filter active when I switch report pages?

Use Power BI's built-in Sync Slicers panel (View → Sync Slicers). Add the Chip Slicer to all pages where you want the filter to persist. Chip Slicer fully supports slicer sync.

How do I deselect all chips and clear the filter?

If "Show All button" is on (default), click the "All" chip. If it's off, click the currently active chip again to deselect it. In multi-select mode, deselect each chip individually or enable the "All" button.

The visual shows a placeholder icon instead of chips. What happened?

No field has been added to the Category well. Drag a column from your data model into the Category field well in the Visualizations panel. The placeholder disappears as soon as a field is assigned.

Can I use Chip Slicer as a regular filter for any column?

Yes. Any categorical column works — text, numbers, dates, booleans. The visual passes its selections to Power BI as a standard BasicFilter, so it interacts correctly with all other visuals on the page.

Does Chip Slicer support High Contrast mode?

Yes. When Power BI's high contrast theme is active, Chip Slicer automatically reads the theme's foreground and background colors and applies them to the chips, ignoring the custom color settings.

Can I navigate chips with the keyboard?

Yes. Use Tab to move between chips, and Enter or Space to toggle selection on the focused chip.

Does this visual collect any data or make network calls?

No. Chip Slicer processes all data locally within your Power BI environment. It makes no external network requests, collects no telemetry, and stores no data outside the report file. See the Privacy Policy for full details.
